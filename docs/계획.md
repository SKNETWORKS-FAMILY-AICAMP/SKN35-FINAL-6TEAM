# 내 역할 주차별 계획

> 1차 초안 · 기준: 사용자가 작성한 주차별 큰 흐름과 인수인계 문서의 담당 업무 · 검토일: 2026-11-16
> 세부 담당자·완료 기준은 팀 협의와 사용자 검토 후 조정합니다.

## 역할 범위

상품 DB와 공통 상품 형식, Adapter, 검색·추천(설계팀), 에이전트 프로토콜, LangGraph 오케스트레이터, RAG를 중심으로 진행합니다. RAG 자료는 사용자별로 PC 구성이 달라지는 점을 반영해 특정 완성 PC 모델을 고정하지 않고, 지원 부품 카탈로그와 제조사 공식 사양·호환성 자료를 기준으로 검토합니다.
