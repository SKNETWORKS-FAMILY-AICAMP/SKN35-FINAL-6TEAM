# 하드웨어 상담 RAG 추가 자료 · 2026-11-19

제조사 공식 문서 19개에서 한국어 상담 질문과 답변 근거 32개를 정리했다. 모델, 부품 번호, 설치 위치에 따라 답이 달라지는 경우 적용 조건을 본문에 적었다. 출처 19개와 청크 32개는 모두 [11월 18일 통합본](../2026-11-18/)에 추가하는 자료다. 두 묶음을 합치면 출처 102개와 청크 85개다.

## 엑셀로 확인하기

[추가 자료 엑셀](../../../data/rag/releases/2026-11-19/BUILDWISE_RAG_추가자료_2026-11-19.xlsx)의 `RAG_청크` 시트에서 질문과 본문을 확인한다. `출처_통합`에서 제조사와 공식 URL을, `원문_통합`에서 원문의 해당 절과 짧은 발췌를 확인할 수 있다. 질문은 자료 정리를 위해 작성한 예시다. `verified`는 표시된 모델과 조건을 제조사 문서에서 확인했다는 뜻이다.

| 분류 | 질문 수 | 다루는 질문 예시 |
|---|---:|---|
| 케이스·냉각 | 9 | NH-D15 G2에서 전면 팬을 올리면 케이스 높이가 얼마나 필요한가? |
| 메인보드·저장장치 | 10 | 두 번째 M.2 SSD를 추가한 뒤 어떤 SATA 포트가 비활성화되는가? |
| 모니터·도크 | 8 | WD19로 모니터 두 대를 연결할 때 어떤 출력 단자를 함께 쓸 수 있는가? |
| 메모리 업그레이드 | 3 | 같은 16 GB DDR5-4800이라도 데스크톱용과 노트북용 모듈이 어떻게 다른가? |
| 서버 메모리 | 2 | CPU가 한 개 장착된 PowerEdge R760에서 어느 DIMM 슬롯을 쓸 수 있는가? |

## 검색용 파일

- [검색 청크](../../../data/rag/releases/2026-11-19/normalized/rag_chunks_normalized.jsonl)에는 `chunk_text`와 `metadata.question`이 있다. `metadata`에는 적용 모델, 주제, 원문 위치, 공식 URL, 확인일도 담았다.
- [출처 목록](../../../data/rag/releases/2026-11-19/normalized/source_master.jsonl)의 `source_key`로 문서명과 제조사 URL을 찾는다. 신규 키는 `SOURCE-084`부터 `SOURCE-102`까지다.
- [문서 발췌](../../../data/rag/releases/2026-11-19/normalized/crawl_records_normalized.jsonl)는 문서마다 대표 구절 하나와 해당 절에서 정리한 한국어 본문을 담았다. 신규 발췌 ID는 `CRAWL-148`부터 `CRAWL-166`까지다. `content_hash`는 대표 구절의 UTF-8 바이트에 계산한 FNV-1a 32비트 값이다.
- [발췌와 청크 연결표](../../../data/rag/releases/2026-11-19/normalized/crawl_chunk_map.jsonl)는 발췌 한 건에 어떤 청크가 연결되는지 보여준다. 청크의 전역 키는 `chunk_key`다.

11월 18일 자료와 함께 사용할 때는 각 묶음의 같은 이름 JSONL을 함께 읽는다. 추후 엑셀에서 내용을 수정하면 검색용 JSONL에도 반영해야 한다.
