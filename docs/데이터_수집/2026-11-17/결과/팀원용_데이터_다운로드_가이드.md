이 문서는 BUILDWISE 데이터 수집 결과를 내려받을 때 필요한 파일과 용도를 안내합니다. 자료는 `ssu` 브랜치의 `docs/데이터_수집/2026-11-17/` 아래에 있습니다.

## 한 번에 받기

- [벤치마크 전체 파일 ZIP 다운로드](https://raw.githubusercontent.com/SKNETWORKS-FAMILY-AICAMP/SKN35-FINAL-6TEAM/ssu/docs/%EB%8D%B0%EC%9D%B4%ED%84%B0_%EC%88%98%EC%A7%91/2026-11-17/%EB%8B%A4%EC%9A%B4%EB%A1%9C%EB%93%9C/benchmark_datasets_2026-11-17.zip)
- ZIP 크기: 57,531,539 bytes
- SHA-256: `57B8458E2813EFA16283BE37534257A80158F3E14BF933E9BC327A676E23AFA3`

압축을 풀면 다음 두 CSV가 나옵니다.

| 파일 | 행 수 | 용도 |
|---|---:|---|
| `benchmark_runs_load_ready.csv` | 498,704 | 부품 연결이 확인된 run의 적재 검토 후보. 실제 DB에 넣기 전 ERD/필드 매핑 확인 필요 |
| `benchmark_runs_preview.csv` | 638,587 | 매칭 보류까지 포함한 전체 변환 검토본. 분석·감사용이며 그대로 DB에 넣는 파일이 아님 |

Windows PowerShell에서 압축을 풀고 SHA-256을 확인할 수 있습니다.

```powershell
Expand-Archive .\benchmark_datasets_2026-11-17.zip -DestinationPath .\benchmark_datasets_2026-11-17
Get-FileHash .\benchmark_datasets_2026-11-17.zip -Algorithm SHA256
```

## 원본 데이터가 필요한 경우

원본 파일은 GitHub에 복제하지 않았습니다. 정규화 결과를 검토하는 데 원본이 필요하지 않으며, 재현이 필요할 때만 아래 고정 출처에서 내려받습니다.

- PC 부품 CSV 8종: [고정 커밋의 data/csv](https://github.com/docyx/pc-part-dataset/tree/c52a04ca9465c83997ed335f7767b09a2005dd26/data/csv) — 저장소 라이선스와 원천 데이터 이용 조건은 별도 확인
- Blender Open Data: [공식 다운로드](https://opendata.blender.org/download/) — CC0 표기 및 데이터 버전 확인
- llm-speed: [고정 revision의 runs.csv](https://huggingface.co/datasets/llmspeed/llm-speed-benchmarks/resolve/460d03927e5e8b68cb65fb3c6aede6c9e9f5187f/runs.csv?download=true) — CC BY 4.0 출처 표시
- Open GPU Benchmarks: [고정 커밋 결과 YAML](https://github.com/MattyStacks/open-gpu-benchmarks/blob/48310dbad3af46c21918cd0aeeabf6e2d51514c6/data/official/steam_machine_8gb_valve/result_20261109_openbenchmarker_neon_flythrough.yaml) — CC BY 4.0 출처 표시

RAG 공식 문서 정리는 [공유 시트](https://docs.google.com/spreadsheets/d/1fulqsRrHVriKkrGvz5519E7K9cvfnGbmpMyb-HfbVho/edit), 크롤링 기록은 [크롤링 시트](https://docs.google.com/spreadsheets/d/12_xSIi6L61M7BDBZe8gjZFN_Doi7vC39MFktG3TuDlE/edit)에서 확인합니다. 오래된 로컬 Excel/PNG 미리보기는 최신 시트 내용과 다를 수 있어 사용하지 않습니다.

## 주의

- 이 CSV들은 변환·검토 산출물이며 데이터베이스 적재가 완료된 상태가 아닙니다.
- 현재 ERD는 8개 테이블 유지로 정했으며, 벤치마크의 실제 저장 위치와 관계는 DB 담당자와 확인해야 합니다.
- 벤치마크 점수는 workload, 앱/벤치마크 버전, 해상도, 시스템 구성 조건이 맞는 경우에만 비교합니다. 미매칭 장비는 추천 점수에 넣지 않습니다.
