## 출처별 한계

### 게임 — Open GPU Benchmarks
[출처](https://opengpubenchmarks.com/) · [라이선스](https://opengpubenchmarks.com/license/)

20개 설정은 Steam Machine 1대에서 생성된 합성 WebGL2 측정 표본입니다. 특정 실제 게임의 FPS, 여러 GPU의 성능 서열 또는 다른 사용자 PC 성능으로 일반화할 수 없습니다. CC BY 4.0 귀속 정보를 유지해야 합니다.

### 3D 렌더링 — Blender Open Data
[공식 다운로드](https://opendata.blender.org/download/)

이번 로컬 변환은 Blender 4.0 이상 Cycles 렌더 기록 638,347행입니다. CAD 작업 성능을 나타내지 않습니다. Blender 버전·씬·기기 유형·렌더 설정을 맞춘 뒤 비교해야 합니다. 원본 ZIP과 파생 CSV는 로컬에만 두며 팀 저장소에는 올리지 않습니다.

### 로컬 AI — llm-speed
[Hugging Face 데이터 카드](https://huggingface.co/datasets/llmspeed/llm-speed-benchmarks)

고정 revision `460d03927e5e8b68cb65fb3c6aede6c9e9f5187f`에서 CSV 220행을 확보했습니다. 공식 MLPerf 점수가 아니며 모델·backend·양자화·하드웨어·입력 길이 등 실행 조건을 맞춰야 합니다. CC BY 4.0 출처 표시가 필요합니다.

### 음악·영상·사진·CAD·공식 MLPerf

- [DAWbench](https://dawbench.com/)는 테스트 세션 자료 후보이며 결과 점수 DB가 아닙니다. 재사용 조건 확인이 필요합니다.
- [PugetBench Premiere Pro](https://www.pugetsystems.com/pugetbench/creators/premiere-pro/)와 [Lightroom Classic](https://www.pugetsystems.com/pugetbench/creators/lightroom-classic/)은 공개 결과 조회 후보입니다. 자동 수집·재배포 권한은 확인하지 않았습니다.
- [MLPerf Inference results v5.0](https://github.com/mlcommons/inference_results_v5.0)은 공식 결과 후보지만 결과 저장소 라이선스를 확인하지 못해 수집을 보류했습니다.
- CAD는 별도 워크로드·결과 출처가 필요합니다.

## RAG 부품 자료와 분리

사용자가 제시한 [docyx/pc-part-dataset](https://github.com/docyx/pc-part-dataset)은 2025-07-23 기준 저장소를 읽기 전용 검토했습니다. README는 66,778개 부품과 JSON·JSONL·CSV 형식, MIT LICENSE를 표시하고 데이터가 PCPartPicker에서 수집됐다고 설명합니다. 저장소 라이선스와 원천 사이트 데이터 권한은 따로 확인해야 합니다.

이는 상품 카탈로그 전처리 후보이며, 호환성 근거를 대신하지 않습니다. CPU-보드 BIOS 지원, GPU 전원 연결, 케이스 여유 공간, 메모리 QVL 등은 제조사 공식 문서로 보완해야 합니다. 특정 완성 PC를 고정할 필요는 없습니다. 이 자료는 아직 다운로드하지 않았습니다.
