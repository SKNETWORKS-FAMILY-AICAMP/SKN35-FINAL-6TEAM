# BUILDWISE 판매자 고객센터 관리 화면 — 클릭식 프로토타입

## 0. 너의 역할과 목표

너는 B2B SaaS 관리자 화면을 만드는 프론트엔드 디자이너 겸 개발자다.
**BUILDWISE**의 판매자(기업) 고객센터 관리 화면을 **클릭하면 움직이는 시연용 프로토타입**으로 만든다.

- BUILDWISE는 IT 장비(PC 부품·노트북·서버)를 파는 기업에 AI 상담과 고객센터 관리 자동화를 제공하는 B2B 플랫폼이다.
- **진짜 서버·AI·DB는 없다.** 모든 데이터는 코드 안의 가짜 데이터이고, 상담·이슈 처리·에이전트 움직임은 타이머로 **그런 척만** 한다.
- 목표: 발표에서 버튼 몇 번만 누르면 "AI가 상담하고 → 요약해 넘기고 → 이슈를 분류하고 → 관리자가 처리하는" 흐름이 화면에서 살아 움직이는 것.

## 1. 기술 조건

- 서버 없이 브라우저에서 바로 돌아갈 것. React + Tailwind를 쓸 수 있으면 쓰고, 안 되면 HTML 파일 하나로 만든다.
- 차트는 가벼운 차트 라이브러리(예: Chart.js, Recharts) 하나만 쓴다.
- 데이터는 `mockData`로 한곳에 모은다. 실시간 이벤트는 `setTimeout`/`setInterval`로 흉내 낸다.
- 화면 글자는 모두 **한국어**로 쓴다.
- 새로고침하면 처음 상태로 돌아가도 된다(저장 기능 없음).

## 2. 화면 흐름

```
첫 화면(기업 / 개인 고르기)
  └ 로그인(공통: 아이디 · 비밀번호, 아래에 회원가입 버튼)
       ├ 개인 → "손님 상담 화면은 이번 범위 밖" 안내 카드만
       └ 기업 → 판매자 관리 화면 (왼쪽 사이드바 메뉴 7개)
```

### 2-1. 첫 화면 · 로그인 · 회원가입

- 첫 화면: 큰 카드 두 개 **[기업]** **[개인]**.
- 로그인 화면은 둘 다 같다: 아이디, 비밀번호, [로그인] 버튼, 그 아래 [회원가입].
- 회원가입:
  - 개인: 아이디 + 비밀번호
  - 기업: 아이디 + 비밀번호 + **기업 인증번호**(팀 지정번호·사번)
- 기업 인증번호는 미리 정한 값만 통과한다. 예: `BW-1001` → "가상전자", `BW-2002` → "테스트컴퓨터". 틀리면 "등록되지 않은 기업 인증번호입니다" 표시.
- 로그인은 아무 값이나 넣으면 통과(시연용). 대신 로그인 화면에 **[관리자로 시연]** **[상담원으로 시연]** 빠른 버튼 두 개를 둔다.
- 로그인 후 상단 바에 회사 이름, 사용자 이름, 역할 배지(관리자 / 상담원), [로그아웃].

### 2-2. 역할별 권한

| 메뉴 | 관리자 | 상담원 |
|---|---|---|
| 홈 · 고객 정보 조회 · 상담·이슈 현황 · 2D 오피스 | 보임 | 보임 |
| 악성 사용자 차단 / 해제 | 가능 | [차단 요청] 버튼만 |
| 판매 통계 · 문서·정책 관리 · 직원 관리 | 보임 | 사이드바에서 자물쇠 표시, 누르면 "관리자 전용" 안내 |

## 3. 판매자 관리 화면 메뉴 7개

### ① 홈 대시보드
- 요약 카드 4개: 오늘 상담 수, 처리 대기 이슈, 오늘 판매 건수, 욕설 감지 알림.
- 잘 팔리는 부품 TOP 5 (가로 막대).
- 최근 활동 피드: "상담 #1042 요약이 고객센터로 전달됨" 같은 한 줄이 위에서부터 쌓인다.
- 카드 숫자는 이벤트가 생길 때 **숫자가 올라가는 애니메이션**과 함께 바뀐다.

### ② 고객 정보 (탭 2개)
**탭 A. 고객별 조회**
- 검색창(이름·고객 ID), 필터(유형: 개인 / 학생 / 스타트업 / 연구실).
- 표: 고객 ID, 이름, 유형, 최근 상담일, 견적 수, 상태(정상 / 차단).
- 행을 누르면 오른쪽에서 상세 패널이 밀려 나온다:
  - 기본 정보, 견적서 목록(견적 번호·금액·날짜, 누르면 견적 미리보기 모달)
  - 상담 이력(날짜별 목록, 누르면 채팅 기록 펼침)
  - **상담 요약 카드**: 요청 · 추천 결과 · 사람이 확인할 점 (전달 에이전트가 만든 것처럼 표시)

**탭 B. 악성 사용자 관리**
- 위: **욕설 자동 감지 목록** — 감지된 문장(욕설 부분은 `***`로 가림), 고객 ID, 시각, [차단] [무시].
- 아래: **차단된 사용자 목록** — 차단 사유, 처리자, 차단일, [해제].
- 블랙컨슈머는 고객 상세 패널의 [차단] 버튼으로 관리자가 직접 차단한다(사유 입력 모달).
- 상담원 계정이면 [차단] 대신 [차단 요청]이 보이고, 누르면 "관리자에게 요청했습니다" 토스트.

### ③ 판매 통계 (관리자만)
- 고객별이 아니라 **항목별 · 부품별** 통계다. **재고 수량은 다루지 않는다.**
- 기간 토글: [일] [주] [월] → 차트가 부드럽게 바뀐다.
- 차트: 카테고리별 판매 비중(도넛), 부품별 판매량 TOP 10(막대), 기간별 추이(선).
- **상담 수요 vs 실제 판매**: 상담에서 많이 물어본 부품과 실제 판매량을 나란히 보여 주는 막대.
- 견적 → 구매 전환율 카드.

### ④ 상담 · 이슈 현황 (별도 메뉴)
- 위: 실시간 카운터 — 상담 중, 대기, 오늘 완료.
- 아래: **이슈 · 클레임 처리함** 칸반 4열: `받음` → `분류됨` → `처리 중` → `완료`.
- 카드: 종류 배지(이슈 / 클레임 / 오류), 고객 ID, 한 줄 요약, 담당자.
- 카드를 누르면 상세: 상담 요약, 업무 보조 에이전트의 처리 제안, [담당자 지정] [완료 처리] 버튼.
- 새 카드가 들어오면 `받음` 열 맨 위에 살짝 튀어 들어오고, 에이전트가 분류하면 `분류됨`으로 미끄러지듯 옮겨 간다.

### ⑤ 문서 · 정책 관리 (관리자만)
- 문서 목록: 공지, FAQ, AS 정책 (제목, 수정일, "상담 에이전트 반영됨" 배지).
- [문서 올리기] → 파일 선택은 흉내만, 2초 동안 "상담 에이전트에 반영 중…" 진행 바 → "반영 완료" 배지.
- 판매 정책: 배송비, 할인율 입력칸 → [저장] 시 "견적에 반영되었습니다" 토스트.

### ⑥ 직원 관리 (관리자만)
- 표: 이름, 아이디, 역할, 상태(승인 대기 / 활성 / 비활성).
- [승인] [역할 변경] [비활성화] 버튼. 승인 대기 1~2명을 미리 넣어 둔다.

### ⑦ 2D 오피스 (보기 전용)
- 위에서 내려다보는 **미니 오피스**. 사용자는 최고 관리자 시점이다. 귀여운 픽셀풍 또는 플랫 일러스트풍.
- 자리 3개와 에이전트 캐릭터 3명:
  | 자리 | 에이전트 | 하는 일 |
  |---|---|---|
  | 상담 창구 | 상담 에이전트 | 손님과 상담 중(말풍선 "예산이 어떻게 되세요?") |
  | 전달 데스크 | 전달 에이전트 | 상담 요약을 서류로 만들어 옆자리로 넘김 |
  | 업무 보조 부서 | 고객센터 업무 보조 에이전트 | 서류를 이슈 / 클레임 / 오류 서랍으로 분류 |
- **서류 아이콘이 자리 사이를 실제로 이동**하는 애니메이션이 핵심이다.
- 에이전트나 서류를 누르면 작은 카드: 건 번호, 현재 상태(받음 → 분류 → 처리 중 → 완료), 요약 한 줄.
- 오른쪽에 작업 로그가 한 줄씩 쌓인다.
- 이 화면에는 차단·완료 같은 **처리 버튼을 두지 않는다**. 처리는 ②·④ 메뉴에서 한다. 카드에 [처리함에서 보기] 링크만 둔다.

## 4. 시연 컨트롤 (가장 중요)

화면 오른쪽 아래에 접었다 펼 수 있는 **"시연 패널"**을 둔다. 버튼을 누르면 가짜 이벤트가 흘러 모든 메뉴가 함께 바뀐다.

| 버튼 | 일어나는 일 (순서대로, 약 1~2초 간격) |
|---|---|
| **[새 상담 들어옴]** | 홈 "오늘 상담 수" +1 → 2D 오피스 상담 창구에 손님 등장, 말풍선 대화 3~4개 → 활동 피드 "상담 #N 시작" |
| **[상담 끝 → 전달]** | 2D 오피스에서 서류가 상담 창구 → 전달 데스크로 이동 → 고객 상세에 상담 요약 카드 생김 → 피드 "요약 전달됨" |
| **[클레임 발생]** | 서류가 업무 보조 부서로 이동 → 클레임 서랍으로 분류 → 처리함 `받음`에 카드 → 1.5초 뒤 `분류됨`으로 이동 → 홈 "처리 대기 이슈" +1 |
| **[욕설 감지]** | 상단 알림 토스트 "욕설이 감지되었습니다" → 악성 사용자 탭에 새 행(욕설은 `***`) → 홈 알림 카드 +1 |
| **[판매 발생]** | 판매 통계 막대 하나가 늘어나는 애니메이션 → TOP 5 순위가 바뀌면 자리 바꿈 애니메이션 |
| **[전체 시나리오 자동 재생]** | 위 5개를 약 30초 동안 차례로 자동 실행. 발표에서 이 버튼 하나만 눌러도 되게 한다 |
| **[처음으로]** | 모든 데이터를 처음 상태로 |

- 어느 메뉴에 있든 이벤트는 적용된다. 다른 메뉴에서 일이 생기면 사이드바 해당 메뉴 옆에 빨간 점이 뜬다.
- 고객과 실제로 대화하는 기능은 없다. 말풍선·채팅 기록은 미리 써 둔 대사를 순서대로 보여 줄 뿐이다.

## 5. 가짜 데이터

- 회사 2개: 가상전자(`BW-1001`), 테스트컴퓨터(`BW-2002`).
- 직원 5명(관리자 1, 상담원 3, 승인 대기 1). 이름은 "김상담"처럼 누가 봐도 가짜인 이름을 쓴다.
- 고객 20명: 유형 섞기(개인·학생·스타트업·연구실), 2명은 차단 상태.
- 부품: CPU, GPU, RAM, SSD, 메인보드, 파워, 노트북 — 모델명은 실제 제품 계열처럼(예: "RTX 4070급 그래픽카드"), 가격은 원화.
- 견적서 30건, 상담 이력 40건, 이슈 카드 8장(각 열에 나눠 배치).
- 상담 대사 예시: "로컬에서 LLM 돌릴 PC가 필요해요" / "예산은 200만 원 정도요" / "지금 쓰는 그래픽카드는 GTX 1060이에요".
- 욕설 예시는 실제 욕 대신 `***`로만 표시한다.

## 6. 디자인

- 밝은 배경의 깔끔한 B2B 관리자 화면. 왼쪽 사이드바, 위 상단 바, 가운데 카드형 본문.
- 포인트 색 하나(청록 계열)와 상태 색(성공 초록, 경고 주황, 위험 빨강)만 쓴다.
- 움직임은 짧고 부드럽게(0.2~0.6초). 숫자 증가, 카드 이동, 서류 이동, 토스트.
- 노트북 화면(1440×900)에서 한 화면에 잘 보이게 한다.

## 7. 하지 말 것

- 실제 로그인·결제·서버 통신 코드 넣지 않기.
- 재고 수량, 재고 부족 알림 넣지 않기.
- 2D 오피스에 처리 버튼 넣지 않기.
- 실제 욕설 문자열 넣지 않기.
- 실제 회사 이름, 실제 사람 이름 쓰지 않기.

## 8. 완성 확인 목록

- [ ] 첫 화면 → 기업 → 로그인 → 판매자 화면까지 막힘없이 넘어간다
- [ ] 기업 회원가입에서 틀린 인증번호는 막힌다
- [ ] 관리자 / 상담원 시연 버튼으로 메뉴 권한이 달라진다
- [ ] 메뉴 7개가 모두 열린다
- [ ] 시연 패널 버튼 7개가 모두 동작하고, 여러 메뉴에 동시에 반영된다
- [ ] [전체 시나리오 자동 재생]이 30초 안팎으로 끝까지 돈다
- [ ] 2D 오피스에서 서류가 자리 사이를 이동한다
- [ ] [처음으로]를 누르면 처음 상태로 돌아간다
