# 2026-11-17 데이터 수집 산출물 요약

## 오늘 확인한 내용

- 어제 수집한 원본 3종(Open GPU Benchmarks 20건, Blender Open Data 638,347건, llm-speed 220건)은 그대로 두고, 오늘 누락 후보를 다시 검색했습니다.
- 누락 후보 검색은 7개 분야, 16개 검색어를 GitHub·Hugging Face에 조회했습니다. 결과 후보는 0건이며 GitHub API 요청 6건이 HTTP 403으로 실패했습니다. 나머지 26회는 요청 오류 없이 검색 결과가 없었습니다. 결과 0건은 해당 데이터가 없다는 뜻은 아닙니다.
- PC 부품 카탈로그 입력 미리보기와 기존 벤치마크의 ERD 매핑 미리보기를 생성했습니다. 현재 파일은 검토용이며 실제 데이터베이스에는 적재하지 않았습니다.
- 별도 공유 시트에 공식 문서 후보·짧은 근거·RAG 청크와 크롤링 원문/기록을 정리했습니다. 공식 출처 9개와 RAG 청크 10개가 기록되어 있고, Blender 요구사항 페이지는 직접 접근이 막혀 부분 확인으로 표시했습니다.
