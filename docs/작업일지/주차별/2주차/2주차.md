## 주요 내용

### 데이터 수집 (11/16~11/17)
- 출처·버전·라이선스를 확인한 파일만 받는 수집 봇을 만들었습니다.
- 게임(Open GPU Benchmarks), 3D 렌더링(Blender Open Data), 로컬 AI(llm-speed-benchmarks) 표본을 확보했습니다. 음악·영상·사진·CAD는 재사용 조건 확인이 필요해 후보로 남겼습니다.
- 정규화 CSV는 적재 검토용입니다. 실제 DB 반영은 ERD 8개 테이블과 매핑을 정한 뒤로 미뤘습니다.

### 기획 변경 (11/18)
- 회의 피드백으로 타깃을 B2B로 바꾸고, 로그인 → 설문 → 상담, 음성 주력·채팅 보조, 고객센터 관리 자동화, 기업 사용자용 2D 부서 화면을 반영했습니다.
- 기존 구조(React · FastAPI · SSE)는 유지하고 음성 처리, 전달·업무 보조 에이전트, 기업 관리 화면, 기업 구분(company_id)을 붙이는 아키텍처 초안을 썼습니다.

### 판매자(어드민) 화면 (11/18~11/19)
- 메뉴 7개(홈 대시보드, 고객 정보, 판매 통계, 상담·이슈 현황, 문서·정책 관리, 직원 관리, 2D 오피스)와 관리자·상담원 권한을 정했습니다.
- 역할을 고객 화면 2명 · 어드민 2명으로 다시 나눴습니다. ssu 브랜치 담당은 어드민을 맡습니다.
- 어드민 기초 설계: 기존 테이블 3개에 기업 구분 칼럼, 새 테이블 9개, `/api/admin` API와 기업 단위 실시간 이벤트 초안, 폴더 구조 안(제안만).
- 목업 2개를 서버 없이 도는 HTML로 만들었습니다.

## 넘어간 일 (3주차)
- 실제 DB 적재 여부와 벤치마크 매핑 방법 결정
- 어드민 추후 결정 7가지(계정 구조, 로그인 방식, 어드민 앱 위치 등)
- 중간발표 자료(11/24 제출)와 발표(11/26)
