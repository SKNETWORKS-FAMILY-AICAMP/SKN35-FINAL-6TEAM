# BUILDWISE PC 상담 화면 — 클릭식 프로토타입

## 0. 너의 역할과 목표

너는 상담형 커머스 화면을 만드는 프론트엔드 디자이너 겸 개발자다.
**BUILDWISE**의 손님용 **PC 상담 화면**을 **클릭하면 움직이는 시연용 프로토타입**으로 만든다.

- BUILDWISE는 IT 장비를 파는 기업에 AI 상담과 고객센터 자동화를 제공하는 B2B 플랫폼이다. 이 화면은 그 기업의 **손님**이 쓰는 상담 창구다.
- 상담은 두 가지다: **기존 PC 부품 교체**, **신규 PC 조립**.
- 화면 뒤에서는 AI 업무팀 3개가 일한다: **설계팀**(후보 고르기) · **검증팀**(호환성 확인) · **견적팀**(견적 만들기). 손님은 이 팀들이 일하는 과정을 화면에서 볼 수 있다.
- **진짜 서버·AI·DB는 없다.** 상품·호환성·견적은 모두 가짜 데이터이고, 업무팀의 작업은 타이머로 **그런 척만** 한다.
- 목표: 발표에서 버튼 몇 번만 누르면 "설문 → 팀이 후보를 찾고 검증 → 손님이 고름 → 견적 → 승인"이 화면에서 살아 움직이는 것.

## 1. 기술 조건

- 서버 없이 브라우저에서 바로 돌아갈 것. React + Tailwind를 쓸 수 있으면 쓰고, 안 되면 HTML 파일 하나로 만든다.
- 데이터는 `mockData`로 한곳에 모은다. 업무팀 진행은 `setTimeout`으로 흉내 낸다(단계마다 0.6~1.2초).
- 화면 글자는 모두 **한국어**, 가격은 **원화**(예: 389,000원).
- 새로고침하면 처음 상태로 돌아가도 된다.

## 2. 화면 흐름

```
① 상담 유형 고르기  [기존 PC 부품 교체] [신규 PC 조립]
② 상담 전 설문 (유형별로 다름)
③ 상담 화면 — 부품을 한 종류씩 고름
④ 견적 확인 — [승인] 또는 [변경 요청]
⑤ 승인 완료 — 견적 저장 (부품 교체는 결제 화면으로 이동)
```

화면 위에 진행 단계 표시줄(① ~ ⑤)을 항상 보여 준다.

## 3. 화면별 구성

### ① 상담 유형 고르기
- 큰 카드 두 개. 아이콘 + 한 줄 설명.
  - **기존 PC 부품 교체** — "지금 PC에서 바꿀 부품만 골라 드려요"
  - **신규 PC 조립** — "목적과 예산에 맞춰 처음부터 맞춰 드려요"

### ② 상담 전 설문

| 기존 PC 부품 교체 | 신규 PC 조립 |
|---|---|
| 현재 보유 부품 (CPU · 메인보드 · RAM · GPU · 저장장치 · 파워 — 선택 상자) | 전체 예산 (슬라이더 + 숫자 입력) |
| 전체 교체 예산 | 주요 사용 목적 (칩 선택: 고사양 게임 · 이미지 편집 · 동영상 편집 · 사무 · AI 개발) |
| 사용 목적 (칩 선택) | 원하는 성능 (예: "QHD 144프레임", "4K 편집 원활") |
| 지금 겪는 문제 (예: "원하는 게임이 끊겨요", 직접 입력도 가능) | |

- 각 칸에 예시 값을 미리 채워 두는 **[예시로 채우기]** 버튼을 둔다.
- [상담 시작] → ③으로.

### ③ 상담 화면 (핵심)

세 칸 구성.

| 왼쪽 | 가운데 | 오른쪽 |
|---|---|---|
| **업무팀 진행 로그** — 설계팀 · 검증팀 · 견적팀이 한 줄씩 보고 (예: "설계팀: GPU 성능이 목표에 부족합니다. GPU 후보를 찾고 있어요") | **후보 카드 목록** — 지금 고르는 부품의 후보 | **내 구성 · 예산** — 고른 부품 목록, 예산 막대(사용 / 남음) |

- 왼쪽 로그 위에 팀 배지 3개를 두고, 지금 일하는 팀 배지가 깜빡인다(작업 중 → 완료 체크).
- 후보 카드: 제품 이미지 자리(회색 상자), 제품명, 핵심 사양 2~3줄, 가격, [선택].
- 후보가 뜨기 전에는 **설계팀 조회 중 → 검증팀 호환성 확인 중 → 통과 N개** 순서로 진행 표시가 지나간다. 검증에서 떨어진 후보는 "호환 안 됨: 파워 용량 부족"처럼 회색으로 접어서 몇 개 보여 준다.

#### ③-A. 기존 PC 부품 교체
1. 설계팀이 보유 부품과 문제를 보고 **바꿀 부품 유형**을 정해 알려 준다. 예: "GPU와 RAM을 바꾸면 해결됩니다." → 오른쪽에 "교체할 부품: GPU → RAM" 순서 표시.
2. 한 종류씩 진행한다. 먼저 GPU 후보를 조회 → 검증팀이 **보유 부품 + 앞서 고른 교체 부품**과 호환되는지 확인.
3. 통과한 후보를 **가격 오름차순**으로 보여 준다. **가장 저렴한 후보에 강조 테두리와 "AI 추천" 배지**.
4. 손님이 GPU를 고르면 남은 예산이 줄고, **선택한 GPU와 남은 예산을 반영해** RAM 후보를 같은 방식으로 보여 준다.
5. 모든 교체 부품을 고르면 [견적 받기] → ④.

#### ③-B. 신규 PC 조립
1. 부품 순서 단계 표시: **CPU → 메인보드 → RAM → GPU → 저장장치 → 쿨러 → 파워서플라이 → 케이스** (8칸). 지금 단계 강조, 끝난 단계 체크.
2. 각 단계 후보는 사용 목적·목표 성능·남은 예산·**앞에서 고른 부품과의 호환성**을 맞춘 것만 보여 주고, **판매량 높은 순**으로 정렬한다. 1위에 "인기 1위 · AI 추천" 배지.
3. 후보 카드마다 **[이 부품에 예산 더 쓰기]** 링크:
   - 누르면 "이 부품에 얼마까지 쓰실 건가요?" 입력 모달 (빠른 선택 버튼: +10만 / +20만 / +30만).
   - 답하면 더 비싼 새 후보를 추천하고, 전체 예산을 넘으면 **조정 제안 카드**를 함께 보여 준다: "SSD를 2TB → 1TB로 바꾸면 -9만 원 · 변경 후 총액 1,980,000원" + [제안대로 조정] [그대로 진행].
4. 8단계를 모두 고르면 [견적 받기] → ④.

### ④ 견적 확인
- 견적팀이 "견적을 만들고 있어요" 진행 표시 뒤 견적표를 보여 준다.
- 표: 부품 종류, 부품명, 개별 가격, 합계. 위에 견적 버전(v1, v2 …)과 만든 시각.
- 버튼: **[이 견적 승인]** · **[변경 요청]**
- **변경 요청**: 바꿀 부품을 고르고 요청을 적는다(예: "케이스를 흰색으로"). → 그 부품만 설계팀으로 돌아가 **기존 구성과 호환되는** 후보를 다시 보여 준다(흰색 케이스 3개). → 고르면 견적팀이 **v2 견적**을 만들고, 바뀐 줄은 노란 배경으로 표시 → 다시 승인을 받는다.

### ⑤ 승인 완료
- "견적 v2를 저장했습니다" 확인 카드(견적 번호, 저장 시각, 총액).
- **기존 PC 부품 교체**: 저장 완료 뒤 1초 후 **결제 화면**(가짜)으로 이동 — 결제 수단 선택 모양만, [결제하기]를 누르면 "시연용 화면입니다" 안내.
- **신규 PC 조립**: 저장 완료 카드에서 끝 (결제 화면은 이번 범위 밖으로 안내).

## 4. 시연 컨트롤 (가장 중요)

오른쪽 아래에 접었다 펼 수 있는 **"시연 패널"**.

| 버튼 | 일어나는 일 |
|---|---|
| **[부품 교체 자동 재생]** | 예시 설문 입력 → 설계팀이 GPU·RAM 교체 판단 → GPU 후보(AI 추천 강조) → 자동 선택 → RAM 후보 → 선택 → 견적 → 승인 → 결제 화면. 약 30초 |
| **[신규 조립 자동 재생]** | 예시 설문 → CPU부터 케이스까지 8단계 자동 선택(GPU 단계에서 "예산 더 쓰기 +20만" → SSD 조정 제안 수락) → 견적 → 케이스 흰색 변경 요청 → v2 견적 → 승인. 약 40초 |
| **[속도 2배]** | 자동 재생 속도 조절 |
| **[처음으로]** | 모든 상태 초기화 |

- 자동 재생 중에는 누르는 대상 버튼이 잠깐 강조되어 "누른 것처럼" 보이게 한다.
- 손님과 실제로 대화하는 AI는 없다. 업무팀 로그는 미리 써 둔 문장을 순서대로 보여 줄 뿐이다.

## 5. 가짜 데이터

- 부품 8종류마다 후보 6~10개: 이름(실제 제품 계열처럼, 예 "RTX 4070급 그래픽카드"), 가격(원화), 판매량, 핵심 사양, 호환 정보(소켓, 메모리 규격, 소비 전력, 케이스 크기, 색상).
- 호환 규칙은 간단히: CPU 소켓 = 메인보드 소켓, 메인보드 메모리 규격 = RAM 규격, 부품 소비 전력 합 × 1.3 ≤ 파워 용량, 그래픽카드 길이 ≤ 케이스 허용 길이.
- 부품 교체 예시: 보유 = i5급 CPU · B660 메인보드 · DDR4 16GB · GTX 1660급 · 500W 파워, 예산 80만 원, 목적 고사양 게임, 문제 "QHD에서 프레임이 낮아요".
- 신규 조립 예시: 예산 200만 원, 목적 동영상 편집 + 게임, 성능 "4K 편집 원활".

## 6. 디자인

- 밝고 친근한 상담 화면. 포인트 색 하나(청록 계열), 추천 강조는 같은 색의 두꺼운 테두리 + 배지.
- 상태 색: 통과(초록), 확인 필요(주황), 호환 안 됨(회색).
- 움직임은 짧고 부드럽게(0.2~0.5초). 후보 카드는 하나씩 떠오르고, 예산 막대는 부드럽게 줄어든다.
- 노트북 화면(1440×900) 기준, 한 화면에 세 칸이 보이게 한다.

## 7. 하지 말 것

- 실제 결제·로그인·서버 통신 코드 넣지 않기.
- 실제 판매처 가격처럼 보이게 하지 않기(가격 옆에 "예시 가격" 표시).
- 실제 회사 이름, 실제 사람 이름 쓰지 않기.

## 8. 완성 확인 목록

- [ ] 두 상담 유형 모두 ① → ⑤까지 막힘없이 간다
- [ ] 부품 교체: 가격 오름차순 + 가장 저렴한 후보에 강조 테두리·"AI 추천" 배지
- [ ] 부품 교체: 두 번째 부품 후보가 첫 선택과 남은 예산을 반영한다
- [ ] 신규 조립: 8단계 순서대로 진행되고 판매량 순 정렬, 앞 부품과 호환되는 후보만 나온다
- [ ] 신규 조립: "예산 더 쓰기" → 금액 질문 → 새 후보 + 조정 제안과 변경 후 총액
- [ ] 견적 변경 요청 → 해당 부품만 다시 고름 → v2 견적, 바뀐 줄 강조 → 재승인
- [ ] 부품 교체 승인 뒤 결제 화면으로 이동
- [ ] 자동 재생 2개가 끝까지 돌고, [처음으로]로 초기화된다
