## 오늘 한 일

- 6개 분야 누락 후보를 GitHub·Hugging Face에서 다시 검색했습니다. 7개 분야, 16개 검색어로 조회했고 후보 0건을 기록했습니다. GitHub API 요청 6건은 HTTP 403, 나머지 26건은 오류 없이 검색 결과가 없었습니다.
- 부품 데이터와 벤치마크를 ERD 적재 검토용 CSV로 정리한 기존 생성 결과를 확인했습니다. 전체 run 638,587건 중 연결 검토 498,704건, 보류 139,883건입니다. 249개 GPU 모델은 판매 SKU가 아닌 참조용 후보입니다.
- 공식 문서/RAG 공유 시트에 공식 출처 9개와 RAG 청크 10개가 기록된 것을 정리했습니다. Blender 요구사항 페이지는 직접 접근 제한으로 일부 확인 상태입니다.
- 봇 코드·오류 로그·인벤토리·manifest·적재 검토 CSV·매칭표·진단 HTML을 `docs/데이터_수집/2026-11-17/` 아래에 모았습니다.
- 전날 코드·보고서·시각화도 `docs/데이터_수집/2026-11-16/`로 이동했습니다.

## 결과와 한계

- 오늘 누락 전용 검색으로 새 데이터 파일을 다운로드하지 않았습니다. 후보 0건은 해당 데이터가 없다는 뜻이 아니며, HTTP 403 및 검색 인덱스 한계가 있습니다.
- 정규화 CSV는 적재 검토용 미리보기입니다. 실제 DB 반영은 하지 않았고, ERD 8개 테이블에 벤치마크 매핑 방법을 확정해야 합니다.
- 원본 데이터는 기존 지시에 따라 GitHub에 복제하지 않고 조회 링크를 기록했습니다. 전체 미리보기 중 100 MiB를 초과하는 CSV 3개는 GitHub 일반 파일 제한으로 제외했습니다. 세부 목록은 `docs/데이터_수집/2026-11-17/결과/제외_파일_목록.json`에 있습니다.
- 개인 승인 설정 `approved_sources.json`은 저장하지 않았고, 비밀값이 없는 `approved_sources.example.json`만 포함했습니다.
