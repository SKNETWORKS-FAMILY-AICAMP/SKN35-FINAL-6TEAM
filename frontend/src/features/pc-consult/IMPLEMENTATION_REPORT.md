## 실행

`frontend`에서 `npm run dev`를 실행한 뒤 `http://localhost:5173/?pc-consult=1`을 엽니다. 기존 화면의 **PC 상담 시작** 링크로도 들어갈 수 있습니다. 백엔드는 필요하지 않습니다.

- 개인: 개인을 고르고 로그인하거나 개인용 시연으로 들어간 뒤 기존 PC 부품 교체나 신규 PC 조립을 고릅니다.
- 기업: 기업을 고르고 관리자나 상담원으로 시연하면 판매자 관리 화면이 열립니다.
- 기업 가입 인증번호: `BW-1001`은 가상전자, `BW-2002`는 테스트컴퓨터. 등록되지 않은 번호는 차단합니다.
- 로그인·회원가입은 시연 진입이며 실제 인증이나 계정 저장을 하지 않습니다. 비밀번호를 저장하거나 서버로 보내지 않습니다.
- 기업 화면 오른쪽 아래 시연 제어의 **전체 시나리오 자동 재생**으로 약 30초 시연을 실행합니다. **처음으로**는 대기 중인 타이머도 취소합니다.

## 구현 범위와 요구사항 해석

개인 상담은 설문, 확인, 순차 부품 선택, 예산 조정, 견적 버전, 승인, 메모리 저장까지 차례로 연결했습니다. 교체 상담만 저장 성공 뒤 결제 연동 예정 화면으로 진행합니다. 이전 견적을 보존하며 변경된 견적은 다시 승인해야 합니다.

기업 화면은 홈, 고객 정보, 판매 통계, 상담·이슈 현황, 문서·정책 관리, 직원 관리, 2D 오피스의 7개 메뉴를 구현했습니다. 공통 이벤트 상태를 사용하여 시연 버튼이 여러 메뉴의 수치·목록·서류 이동·읽지 않은 알림에 함께 반영됩니다. 상담원은 관리 전용 3개 메뉴와 차단·해제·직원 변경 작업이 제한됩니다. 오피스는 보기 전용이며 처리함으로 이동하는 링크만 있습니다.

추가 기업 요청의 “개인 화면은 범위 밖” 문구는 기업 프로토타입 설명의 범위로 해석했습니다. 사용자가 **추가적으로** 요청했으므로 먼저 요청한 개인 PC 상담 기능을 유지했습니다.

원문 요구사항의 DB 저장·판매량순 추천은 이번 작업의 명시적 제한을 적용했습니다. 개인 견적은 `confirmQuote()`에 `quotes`/`quote_items` 형태를 전달하고 **시연 저장 (DB에 기록 안 됨)**으로 표시합니다. 판매량을 만들지 않고 **추천 기준: 가격 낮은 순 (판매량 데이터 준비 중)**을 표시합니다. 개인 부품은 제공된 스냅샷만 사용합니다. 기업 통계의 가상 상품·판매량은 별도 `seller/mockData.ts`에만 있으며 개인 추천에 사용하지 않습니다.

차트는 기존 React와 SVG/CSS로 작성했습니다. 새 패키지, Tailwind 설정, 차트 라이브러리는 추가하지 않았습니다. 문서 선택도 가상 목록을 사용하며 실제 파일 업로드·외부 결제·인증 API 호출은 없습니다.

| ----------- | ---------------------------------- | --------------------- |

## API 제안 요약

`API_PROPOSAL.md`에 경로·요청·응답 예시를 작성했습니다.

- `POST /api/pc-consult/candidates`: 설문·현재 구성·예산·색상에 따른 통과/확인 필요 후보.
- `POST /api/pc-consult/validations`: 구성 호환성, 근거·조건·미확인 항목.
- `POST /api/pc-consult/quotes`: 서버가 다시 계산한 가격·총액과 새 견적 버전.
- `POST /api/pc-consult/quotes/{quote_id}/confirm`: 버전·당시 품목 스냅샷 확인, 중복 요청 방지, 저장 결과.

실제 공통 API 경로나 계약은 변경하지 않았습니다. 채택 시 별도 계약 변경 PR이 필요합니다. `apiSource`는 미연결 오류를 명확히 반환하며 실제 네트워크 호출을 하지 않습니다.

Playwright는 저장소에 이미 설치된 패키지를 사용했습니다. 최초 브라우저 실행 파일이 없어 승인 후 Chromium을 `frontend/node_modules/.cache/pc-consult-browsers`에 내려받았습니다. 임시 프로필도 `frontend/node_modules/.cache/pc-consult-temp` 안에서 사용했습니다. 재실행 시 PowerShell에서 아래 환경을 설정합니다.

```powershell
$env:PLAYWRIGHT_BROWSERS_PATH = Join-Path (Get-Location) 'node_modules/.cache/pc-consult-browsers'
$env:TEMP = Join-Path (Get-Location) 'node_modules/.cache/pc-consult-temp'
$env:TMP = $env:TEMP
node src/features/pc-consult/verification/verify-ui.mjs
node src/features/pc-consult/verification/verify-seller.mjs
```
