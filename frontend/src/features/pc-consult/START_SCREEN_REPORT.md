# 시작 화면 개선

2026-11-20. 기업·개인 선택과 시연 로그인 화면을 같은 시각 구성으로 정리했습니다.

## 변경

- 깊은 청록색 소개 영역, 밝은 계정 선택 영역으로 대비를 만들었습니다.
- 기업의 상품·정책을 연결하는 서비스 설명과 상담 → 설계·분석 → 검증 → 견적·주문 흐름을 표시합니다.
- 기존 단순 PC 그림을 금속 케이스·강화유리·CPU·RAM·GPU·팬과 반사광이 있는 SVG 일러스트로 교체했습니다. 확대해도 선명하며, 실제 상품 사진이 아닌 예시라는 설명을 붙였습니다.
- 팬 회전과 조명은 장식입니다. 실제 업무 진행이나 상품 성능을 나타내지 않으며, 움직임 줄이기 설정에서는 멈춥니다.
- 기업·개인 카드에 서로 다른 아이콘과 짧은 기능 설명을 넣었습니다. 로그인·시연 역할·기업 코드 검증 동작은 유지합니다.
- 작은 화면에서는 소개 영역을 줄여 선택 카드를 먼저 사용할 수 있게 했습니다. 로그인 시에는 소개 영역을 한 번 더 줄입니다.

`frontend/src/features/pc-consult/` 기준입니다.

| `components/StartScreen.tsx`                                   | 소개·업무 흐름·선택 카드 구성, 새 비주얼 연결                   |
| `components/entryScreen.css`                                   | 시작 화면에 한정한 색·비율·반응형·포커스 스타일                 |
| `components/WelcomeVisual.tsx`, `components/welcomeVisual.css` | 해상도에 영향을 받지 않는 제품 예시 일러스트와 장식 애니메이션  |
| `verification/verify-start-screen.mjs`                         | 변경 전후 캡처, 세 화면 폭, 로그인·기업 코드·움직임 줄이기 검증 |
| `START_SCREEN_REPORT.md`                                       | 변경과 검증 결과 기록                                           |
