# BUILDWISE UI 재구성 보고

2026-11-20. 고객 화면 비율, 오피스 업무 상세, 부품 이미지가 있는 견적을 중심으로 화면을 다시 구성했습니다.

## 화면에서 달라진 점

- 고객 화면의 기존 절반씩 나누던 배치를 변경했습니다. 1440px에서는 상담·선택 영역에 약 64%, 사무실에 약 33%를 배정하고, 1024px에서는 오른쪽 사무실을 300px로 유지합니다. 360px에서는 상담·선택을 먼저 보여 주고 사무실을 아래로 배치합니다.
- 설문은 기존 요청대로 음성 상담 영역 안에 있습니다. 후보·견적 단계에서는 같은 큰 영역을 부품 선택에 사용하고, 사무실·선택 구성·대화를 보조 영역에 모았습니다. 배치를 바꿔도 대화와 설문 상태를 유지합니다.
- 중첩된 상담 화면에 적용되던 `100vh` 기준 최소 높이를 제거했습니다. 글자 크기, 여백, 입력창, 단계 표시, 제품 카드와 배경색도 함께 정리했습니다.
- 기업 홈은 소개·연결 정보를 하나로 묶고 사무실을 앞세웠습니다. 네 팀 상태는 사무실 아래에 모았고, 지표 카드 네 개는 하나의 지표 띠로 정리했습니다. 인계함, 직원, 피드백, 상품 정책 화면에도 같은 간격과 색을 적용했습니다.
- 오피스에 포인터를 올렸을 때 방을 `scale(2)`로 키우던 동작을 없앴습니다. 팀 방을 누르면 넓은 업무 상세 창이 열립니다. 방 그림에 더해 실제 진행 메시지, 요청 버전, 수신 기록, 동시 작업 수, 기록 시각과 시간 계산 근거를 보여 줍니다.
- 작업 중 문서 정리·모니터 스캔, 복도의 서류 전달, 동시 검증원 움직임을 보강했습니다. `AgentEvent`와 기존 `officeReducer`의 상태를 사용하며, 애니메이션이 완료 상태나 가짜 진행률을 만들지 않습니다. 견적 출력은 기존 `run.completed` 조건을 유지합니다.
- 상세 창은 Escape로 닫히고 선택했던 방으로 포커스가 돌아옵니다. 움직임 정지와 `prefers-reduced-motion`을 유지합니다.

## 부품 이미지와 견적

제공된 스냅샷 9,917행을 확인했으며 **사진 주소가 있는 행은 0개**입니다. 실제 제품 사진을 임의로 연결하지 않았습니다.

- CPU·메인보드·RAM·GPU·저장장치·파워·케이스·쿨러의 SVG 일러스트를 코드로 그렸습니다. 후보, 선택 구성, 견적, 저장·결제 요약에서 같은 컴포넌트를 사용합니다.
- 실제 제품 사진이 없는 곳에는 **제품 이미지 미등록 · 분류 예시**라고 표시합니다. 특정 제품의 외형을 보증하는 그림이 아닙니다.
- 유효한 `image_url`이 제공되면 제품 사진을 표시합니다. 로딩 실패 시 그림으로 돌아가며 실패 안내를 표시합니다.
- 견적에는 부품 그림, 브랜드, 제품명, 수량, 단가와 총액을 함께 표시합니다. 좁은 컨테이너에서는 표의 행을 카드 형태로 배치합니다. 표의 의미 구조와 기존 변경 요청·버전 이력을 유지합니다.
- 이전 견적의 그림을 찾을 수 있도록 `source_key` 기준의 화면용 이미지 정보를 메모리에 유지합니다. 저장 요청의 `quotes`·`quote_items` 형식은 바꾸지 않았습니다.

고객 화면에서는 가로 넘침·페이지 오류·백엔드 API 요청이 없었고, 넓은 화면에서 결정 영역이 사무실보다 큰지, 설문 후에도 대화가 남는지 확인했습니다. 후보·견적과 기업 15개 화면도 가로 넘침·페이지 오류 없이 진행됐습니다. 업무 상세는 동시 검증 수와 실제 이벤트를 표시하며 화면 폭에 맞게 열리는지 확인했습니다.

기업 전체 회귀 검증도 통과했습니다. 상품 메타데이터, 기업별 추천 차이, 할인 한도를 3%에서 7%로 바꾼 뒤 인계 조건 변화, 고객 미리보기, 인계 상세, 피드백에서 정책 화면 이동, 발표 7단계와 초기화, 상담원 권한 제한을 세 폭에서 확인했습니다. 페이지 오류·가로 넘침·백엔드 API 요청은 없었습니다.

## 유지한 범위와 한계

- Git 명령, 패키지 추가, 백엔드·공통 계약·DB·공유 설정·스냅샷 변경 없음.
- 실제 상품 사진 수집이나 사진 데이터 추가는 하지 않았습니다. 현재 견적의 그림은 분류별 일러스트입니다.
- 추천·호환성·가격과 기업 정책의 판단 규칙은 그대로입니다. 기업 통계의 가상 표시, 테스트 가격, 확인 불가 경고도 유지합니다.
- 로그인·결제·저장은 기존 시연 방식이며, 담당자 확인이 필요한 견적은 계속 자동 확정을 막습니다.
- 기존 템플릿 출처 주석과 `THIRD_PARTY_NOTICES.md`를 유지했습니다. 이번에 새 외부 템플릿이나 이미지 소스를 추가하지 않았습니다.
