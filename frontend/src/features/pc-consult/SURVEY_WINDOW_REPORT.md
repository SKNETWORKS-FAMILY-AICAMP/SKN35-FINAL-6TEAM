# 설문 창 개선

2026-11-20. 길게 늘어나는 설문을 화면 안의 작성 창으로 옮겼습니다.

## 동작

- 상담 유형을 고르면 설문 창이 열립니다. 설문 작성과 입력 내용 확인을 같은 창에서 진행합니다.
- 설문 내용만 내부에서 스크롤되고, 창 머리글과 아래의 이전·확인 버튼은 고정됩니다.
- 크게 보기·기본 크기·접기를 지원합니다. 접기나 Escape를 눌러도 작성 중인 입력과 검색 상태를 유지합니다.
- 접은 뒤 상담 패널의 ‘설문 계속 작성’ 또는 ‘설문 확인하기’로 다시 엽니다. 사무실과 대화는 그대로 유지합니다.
- 상담을 시작하면 창이 닫히고 기존 후보 선택 화면으로 이어집니다.
- 360px에서는 화면 가장자리에 8px 여백을 남겨 작성 영역을 확보합니다.
